# HRBOSS 招聘助手

BOSS直聘 网页版自动化招聘助手：**精准筛选候选人 → 批量打招呼 → AI 自动回复 → 沉寂候选人复聊唤醒**，带图形界面，全程在你自己电脑上运行。

用 Python + [DrissionPage](https://github.com/g1879/DrissionPage) 驱动本机已安装的 Chrome / Edge 浏览器操作网页版。没有服务端、不上传任何数据：岗位配置、候选人记录、API Key 全部只存在本机。

> 仅适用于持有 BOSS直聘 招聘者账号的企业招聘场景。使用前请阅读文末[免责声明](#免责声明)。

## 功能特性

| 模块 | 说明 |
| --- | --- |
| **精准筛选** | 学历、年龄、性别、活跃度、薪资区间、跳槽频率、公司关键词（包含/屏蔽）、排除词，维度比多数同类工具更细 |
| **批量打招呼** | 每日上限、工作时段、随机间隔、机器自适应频率，控制节奏避免过快 |
| **AI 自动回复** | 高频问题先命中本地关键词规则库（零延迟、零 API 成本），未命中才调用 DeepSeek，并按真人打字速度发送 |
| **复聊唤醒** | 对沉寂 N 天的候选人定时唤醒，默认低频保守（小时级才唤醒一人） |
| **去重记忆** | 联系过的候选人写入指纹文件，避免重复打扰同一人 |
| **知识库** | 公司介绍 + 分岗位信息喂给 AI 作背景；问答规则为硬命中，两者都直接是纯文本/JSON 文件，随时改 |
| **图形界面** | Tkinter 面板，无需命令行；AI 面板独立开关，可单独启停自动回复与复聊 |

## 环境要求

- **Windows 10 / 11**（代码使用了 `winreg` 查找浏览器安装路径）
- **Python 3.9+**，且需自带 `tkinter`（Windows 官方安装包默认包含）
- 本机已安装 **Chrome 或 Edge**
- 一个 **BOSS直聘 招聘者账号**
- （可选）**DeepSeek API Key** — 用于 AI 自动回复，在 https://platform.deepseek.com 申请；不填则只走本地规则库

## 快速开始

**1. 获取代码**

```bash
git clone https://github.com/zhbo192883/HRBOSS.git
cd HRBOSS
```

**2. 安装依赖**

```bash
pip install -r requirements.txt
```

**3. 启动程序**

```bash
python boss_recruiter.py
```

**4. 连接浏览器并登录**

在界面点击「启动浏览器」，在弹出的浏览器窗口中扫码登录 BOSS直聘 招聘者账号。登录态会保存在 `browser_runtime/` 下，下次启动无需重复登录。

**5. 配置筛选条件**

在左侧「精准筛选」区填写岗位名称、学历、年龄、薪资等条件，点击开始运行，程序会按条件筛选并逐个打招呼。

## 配置 AI 自动回复

1. 点击界面顶部的 **「AI 自动回复」** 按钮，打开 AI 设置面板。
2. 填入 **DeepSeek API Key** 并保存。
3. 点「打开公司介绍」「打开问答规则」，把示例内容替换成你公司的真实信息 — 这一步直接影响 AI 回复质量。
   - `knowledge/company_info.md` — 公司背景、分岗位说明；支持 `## 岗位：采购专员` 这样的分段写法，AI 会按当前岗位取对应内容。
   - `knowledge/qa_rules.json` — 关键词 → 固定答案，例如「薪资」「五险一金」，命中后不消耗 API。
   - 这两个文件**首次打开 AI 面板时自动生成**，改完点「重新加载知识库」生效。
4. 点击「启动 AI 自动回复」/「启动复聊唤醒」，面板下方日志窗口会实时输出运行状态。

### 关于风控参数

AI 面板默认已是**低频稳妥**配置（回复轮询 25~55 秒一轮、复聊 2~6 小时才唤醒一人、模拟真人打字延迟）。建议先用默认值跑几天观察效果。

**不建议调得更激进** — 尤其是「复聊唤醒」，这是最容易被平台判定为骚扰/机器人的行为。所有涉及频率的参数都可在面板中调整，请自行权衡账号风险。

## 项目结构

```
HRBOSS/
├── boss_recruiter.py      # 主程序：Tkinter 界面、筛选逻辑、浏览器驱动、打招呼主循环
├── ai_panel.py            # AI 设置面板（独立窗口）
├── chat_ai_engine.py      # 会话轮询、未读检测、AI 回复生成与发送
├── knowledge_base.py      # 知识库加载 + 关键词规则引擎
├── deepseek_client.py     # DeepSeek Chat Completions 封装
├── ai_config.py           # AI 模块配置读写
├── rate_limiter.py        # 频率限制、工作时段判断、拟人化延迟
├── requirements.txt
├── AI功能说明.md           # AI 模块详细使用说明（含选择器失效的修复方法）
└── AI功能说明_更新说明.md
```

以下目录**首次运行时自动创建**，已被 `.gitignore` 排除：

| 目录 / 文件 | 内容 |
| --- | --- |
| `browser_runtime/` | 浏览器用户数据与缓存（含登录态，体积可能数百 MB） |
| `logs/` | 运行日志、匹配/跳过候选人导出 CSV |
| `contacted_fingerprints.json` | 已联系候选人指纹（去重用） |
| `knowledge/` | 公司介绍与问答规则 |

## 数据与隐私

- 所有数据**只保存在本机**，程序不向除 DeepSeek API 之外的任何服务器发送信息。
- 启用 AI 自动回复时，最近的对话上下文与你的公司介绍会发送给 DeepSeek 用于生成回复。若候选人不希望对话内容被第三方处理，请关闭 AI 功能。
- `logs/` 下的候选人导出文件、`contacted_fingerprints.json` 均含**真实个人信息**，已被 `.gitignore` 排除。**请勿将其提交到任何公开仓库**，并在分享截图/日志前自行脱敏。
- `knowledge/company_info.md` 通常包含招聘负责人微信号与手机号，同样已排除。

## 常见问题

**Q：程序提示找不到会话列表 / 未读消息？**
BOSS直聘 改版会导致页面选择器失效。`chat_ai_engine.py` 顶部的 `SELECTORS` 字典集中存放了所有选择器，日志会明确提示卡在哪一步；按 F12 找到真实元素的 class 名，往对应条目里追加一行即可，无需重启程序（详见 `AI功能说明.md` 第 4 节）。

**Q：一定需要 DeepSeek API Key 吗？**
不需要。只填 `qa_rules.json` 也能工作 — 规则命中的常见问题会正常回复，只是规则未覆盖的问题不会有 AI 生成答案。

**Q：登录态丢失 / 需要重新扫码？**
删除 `browser_runtime/` 目录重新登录即可。这也是程序更新后遇到浏览器异常时的通用排查手段。

**Q：支持 macOS / Linux 吗？**
当前版本调用了 Windows 注册表查找浏览器路径，未适配其他系统。欢迎提交 PR。
